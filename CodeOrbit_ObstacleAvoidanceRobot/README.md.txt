# Obstacle Avoidance Robot Using Ultrasonic Sensor

## Project Description
This project demonstrates an obstacle avoidance robot using an Arduino Uno and an HC-SR04 ultrasonic sensor.

## Components
- Arduino Uno
- HC-SR04 Ultrasonic Sensor

## Working Principle
The ultrasonic sensor measures the distance between the robot and nearby objects.

- If distance is greater than 20 cm, the robot moves forward.
- If distance is 20 cm or less, the robot stops and turns right.

## Software Used
Wokwi Arduino Simulator

## Project Objective
To understand how sensors and logical conditions control robotic actions.

## Simulation
The project is tested using different obstacle distances in Wokwi.
